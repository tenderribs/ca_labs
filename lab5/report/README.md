## Generating Measurement Results

### 1. Ramulator 2 Config files

The YAML config files for the different workloads are generated using the Jinja library for Python (`gen_configs.py`). It uses a template YAML file and fills in the correct workloads and, in the case of Bliss and Atlas, it includes the correct plugins. The generated config files are located in `report/yml_configs/all`.

### 2. Running Tests

After building the project using cmake and make, the `test_runner.sh` can be used to run multiple simulations in parallel using the generated configs. You can tweak the number of workers allotted for this. Note that in a Docker container, you might run out of memory for large worker counts (adjust the resources allocated to Docker as necessary). The results of each worker are saved in the `report/ramulator_logs` folder. The simulations for the 0L8H workloads can take a few hours.

### 3. Evaluation

`res_inst_thrput.csv` and `res_max_slowdowns.csv` are the final numerical resuls based on the log files saved in the previous step. They are generated by running the following python scripts:

```sh
python3 report/calc_slowdown.py && python3 report/calc_inst_thrput.py
```
